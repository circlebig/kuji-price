# kuji-price

이치방쿠지(一番くじ) 피규어의 한국·일본 중고 시세를 비교하는 프로토타입입니다.

- **일본**: 야후옥션 낙찰 내역 (실제 낙찰가)
- **한국**: 번개장터 (판매완료가, 부족하면 판매중 포함 등록가)
  - 검색어는 작품마다 `제일복권 {작품}`, `이치방쿠지 {작품}`과, 피규어가 있는 상마다 `{작품} A상` … `{작품} 라스트원`입니다. 제목에 "제일복권"을 쓰지 않는 판매자가 많아서 상 표기 검색이 필요합니다. 이때 따라오는 타사 쿠지(세가, 타이토 등)는 제목 단어로 걸러 냅니다.
- **카탈로그**: 이치방쿠지 공식 사이트의 쿠지·상 목록
- **대상 작품**: 진격의 거인, 나의 히어로 아카데미아, 주술회전, 체인소 맨, 원피스, 드래곤볼, 귀멸의 칼날, 나루토, 사카모토 데이즈 (`common.py`의 `WORKS`에 추가하고 `names.py`에 사전을 넣으면 늘릴 수 있음)

## 실행

Python 3.11 이상이 필요합니다.

```
pip install -r requirements.txt
python run.py all          # 카탈로그 + 전체 수집 + 집계 (약 20분)
python -m http.server 8765 --directory site
```

브라우저에서 http://localhost:8765 를 엽니다.

| 명령 | 하는 일 |
|---|---|
| `python run.py catalog` | 공식 사이트에서 쿠지·상 목록 수집 |
| `python run.py collect` | 야후옥션·번개장터 매물 전체 수집 |
| `python run.py build` | 매칭·집계 후 `site/index.html` 생성 |
| `python run.py quick` | 새 매물만 빠르게 수집하고 집계 |
| `python run.py watch [분]` | 자동 갱신. 기본 60분마다 quick, 하루 한 번 전체 수집 |

## 배포

`main`에 올라간 코드로 GitHub Actions(`.github/workflows/update.yml`)가 매시간 새 매물을 수집하고
GitHub Pages에 페이지를 올립니다. 하루 한 번(한국 시간 새벽 3시 이후 첫 실행)은 카탈로그와 전체 매물을 다시 수집합니다(`python run.py auto`가 판단). GitHub 예약 실행은 늦어지거나 건너뛰는 일이 있어 주기를 짧게 잡았습니다.

- 사이트: https://circlebig.github.io/kuji-price/
- 수동 실행: 저장소의 Actions 탭에서 "시세 갱신 및 배포"를 실행
- 수집 DB는 저장소에 넣지 않고 Actions 캐시로 이어 갑니다. 캐시가 사라지면 다음 실행이 전체 수집부터 다시 합니다.
- 시세가 잡힌 상품이 너무 적으면(수집 차단 등) 배포하지 않고 실패로 끝납니다.

## 구조

| 파일 | 역할 |
|---|---|
| `kujiprice/common.py` | 대상 작품 설정, HTTP 요청(1초 간격), SQLite 스키마 |
| `kujiprice/catalog.py` | 공식 사이트 카탈로그 수집 |
| `kujiprice/sources.py` | 야후옥션·번개장터 매물 수집 |
| `kujiprice/names.py` | 쿠지 부제·캐릭터의 일본어/한국어 키워드 사전 (수작업) |
| `kujiprice/match.py` | 매물 제목 → (쿠지, 상) 매칭, 묶음·비피규어 제외 |
| `kujiprice/build.py` | 최근 120일 중간값 집계, 환율 적용, 페이지 생성 |
| `kujiprice/template.html` | 시세 비교 페이지 템플릿 |

수집 데이터(`data/`)와 생성된 페이지(`site/`)는 저장소에 포함하지 않습니다.

## 가격 비교 방식

- **직구 예상가**: 일본 낙찰가 중간값에 일본 내 배송비, 구매대행 수수료, 국제 배송비, 면세 한도 초과 시 관부가세를 더한 추정값입니다. 구매대행 수수료와 국제 배송비 기본값은 비드바이코리아 공개 요금표(2026년 6월, 일반회원, 항공특송 1kg 이하)를 따랐고, 일본 내 배송비 1,000엔과 관부가세 18.8%(관세 8% + 부가세 10% 가정)는 확인되지 않은 통상값입니다. 모두 페이지의 "직구 비용 가정"에서 이용자가 고칠 수 있습니다(`template.html`의 `A_DEFAULT`, `feeYen`).
- **비교 보류**: 나라별 매물이 너무 적거나(일본 5건, 한국 3건 미만) 한일 가격이 2.5배 넘게 벌어진 상품은 다른 상품이 섞였을 가능성이 커서 가격 차이를 표시하지 않습니다(`build.py`의 `hold_reason`).

## 미국 이치방쇼 가격

같은 피규어의 해외 소매판(ICHIBANSHO)이 미국에서 얼마에 팔리는지를 참고값으로 보여 줍니다.

- 데이터는 `kujiprice/ichibansho_us.json`에 있습니다. 미국 쇼핑몰(Deep Discount)에서 손으로 확인해 넣은 스냅샷이고 자동 갱신되지 않습니다. 해당 사이트는 프로그램의 직접 요청을 막습니다.
- 각 항목의 `kuji`는 `names.py`의 쿠지 부제 키, `letter`는 상입니다. 연결되지 않는 항목은 집계 때 "이치방쇼 연결 실패"로 출력됩니다.
- 배송비와 관부가세는 포함하지 않으며, 직구 예상가 계산에는 쓰지 않습니다.

## 알려진 한계

- 제목만으로 자동 분류하므로 잘못 분류된 매물이 섞일 수 있습니다. 특히 같은 부제의 옛 시리즈가 있는 오래된 쿠지는 부정확합니다.
- 공식 사이트 검색이 작품당 최신 10종만 보여 줘서 그보다 오래된 쿠지는 다루지 않습니다.
- 새 쿠지가 나오면 `names.py`에 한국어 부제와 캐릭터를 추가해야 시세가 잡힙니다.
- 야후옥션과 번개장터는 공식 API가 아니라 웹 페이지가 쓰는 데이터를 읽습니다. 사이트 구조가 바뀌면 수집이 깨질 수 있고, 공개 서비스로 운영하려면 각 사이트 약관을 확인해야 합니다.
